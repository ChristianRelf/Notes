# Notepad

A desktop note pad. Every note is a real `.md` or `.txt` file in one folder on
your computer. It autosaves, it opens notes in tabs, and nothing it holds ever
leaves the device - no account, no sync, no network calls at all.

Rust core, system webview for the window. Around 4.6 MB on disk, ~29 MB of
memory, roughly 200 ms from double-click to a window you can type in.

## Running it

```
src-tauri/target/release/notepad.exe
```

Pin that to the taskbar, or make a Start menu shortcut to it. To build from
source:

```
cd src-tauri
cargo build --release      # ~80 s cold, ~15 s after a UI-only change
cargo test                 # the path, naming and file-writing rules
```

The window's HTML, CSS and JavaScript are compiled into the binary, so a change
under `src/` needs a rebuild. For live reload instead, install the Tauri CLI
(`npm i -g @tauri-apps/cli`) and run `cargo tauri dev`.

## Where the notes live

`Documents\Notepad` by default. Click the folder name at the bottom left to put
them somewhere else - a synced folder, a git repo, wherever. Deletes move to a
`.trash` subfolder; only "Delete for good" removes a file.

Because they are ordinary files you can grep them, back them up, open them in
another editor, or walk away from this app entirely and still have everything.
Edit a file elsewhere and the change appears here straight away; if you are
mid-sentence in the same note, what you are typing wins.

## Keys

| | |
| --- | --- |
| `Ctrl+N` | New note |
| `Ctrl+K` | Jump to a note - type, arrow, Enter. Enter with no match creates it |
| `Ctrl+F` | Search the list |
| `Ctrl+W` | Close the tab |
| `Ctrl+Tab` | Next tab (`Ctrl+Shift+Tab` back, `Ctrl+1`-`Ctrl+9` by number) |
| `Ctrl+E` | Markdown preview |
| `F2` | Rename - this renames the file too |
| `Ctrl+\` | Show or hide the note list (hidden to start with) |
| `Ctrl+Delete` | Move to trash, with Undo |
| `Ctrl+Shift+C` | Copy the whole note |

Right-click a tab or a note in the list for the rest.

## Tabs

One click on a note opens it in an *italic* tab that the next click reuses, so
clicking down a long list does not leave fifty tabs behind. Type in it,
double-click it, or open it from `Ctrl+K` and it becomes a normal tab that
stays. Open tabs come back when you reopen the app.

Scroll or drag anywhere along the tab bar to move through them. The `+` sits
after the last tab and travels with it.

## Titles

A note you have not named takes its title from the first line that has anything
on it, and the file on disk follows along - type `# Shopping` and the file
becomes `Shopping.md`. Rename a note with `F2` and it keeps that name from then
on, whatever you type. Notes brought in from elsewhere keep their filenames.

## Saving

Typing saves 350 ms later, and again on close, on losing focus, and on
`Ctrl+S`. Writes go to a temp file and are renamed over the target, so a crash
mid-save cannot leave you half a note. The header says where you stand -
"Saving…", "Saved just now", or what went wrong.

## Layout

```
src/                  the window: index.html, app.css, app.js - no build step
src-tauri/src/main.rs the folder: scan, save, rename, trash, import, watch
src-tauri/icons/      generated, see the note below
DESIGN_CRITERIA.md    the visual language this follows
```

Notes are read into memory once at startup, so search, the quick switcher and
the tab strip never touch the disk.

The window is a window, not a page: your preferences live in the app's
`settings.json` next to the notes-folder setting rather than in webview
storage, links in a preview open in your real browser, and reload, print and
the browser context menu are off.

The icons were generated by a script rather than drawn by hand; regenerate them
with any PNG of a dark rounded square if you want something else, keeping the
sizes listed in `src-tauri/tauri.conf.json`.
